# Click-Bot Attribution & Ad-Fraud Auditor

A data analytics project that detects bot traffic in Google Analytics data using Python, machine learning, and Power BI.

## Problem Statement

Digital marketing budgets are often wasted due to bot traffic and fraudulent clicks that distort website analytics and advertising performance.

This project analyzes Google Analytics data to identify suspicious traffic, clean marketing data, and calculate the true Return on Ad Spend (ROAS).

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Power BI
- Google Analytics 4
